# Assumptions map

**Date:** **Who took part:**

## 1. Write the assumptions
One per line, as "We believe…". Tag each one **D** (desirable: people want it), **V** (viable: it can pay
or be funded) or **F** (feasible: we can build and run it).

| # | We believe… | D / V / F |
|---|---|---|
| 1 | | |

## 2. Place each one

|  | **Little evidence** | **Lots of evidence** |
|---|---|---|
| **Important** (if wrong, it fails) | **Test first:** | Keep checking: |
| **Less important** | Park: | Ignore for now: |
