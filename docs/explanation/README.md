# Explanation

**Diátaxis kind: explanation.** Background and reasons. The reader wants to understand why the
system is the way it is, what the trade-offs were, and how the parts fit together.

- Name files after the topic: `why-raw-data-stays-separate.md`.
- An explanation can discuss options and history. A decision itself still goes in an ADR
  ([`../adr/`](../adr/README.md)); link to it from here.
- No step-by-step instructions. Link to the how-to guide instead.

Guidance: [diataxis.fr/explanation](https://diataxis.fr/explanation/).
