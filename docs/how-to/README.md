# How-to guides and runbooks

**Diátaxis kind: how-to guide.** A recipe for a reader who already knows what they want to do and
needs the steps. Runbooks live here: a runbook is a how-to guide for an operational task.

- Name the file after the task, as a verb: `restore-the-database.md`, `rotate-a-secret.md`.
- Start a runbook from [`runbook-template.md`](runbook-template.md).
- Steps only. Put the "why" in [`../explanation/`](../explanation/README.md) and link to it.
- Test the steps by following them. A runbook nobody has run is a draft; mark it so in `status`.

Guidance: [diataxis.fr/how-to-guides](https://diataxis.fr/how-to-guides/).
