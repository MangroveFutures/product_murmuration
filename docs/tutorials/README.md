# Tutorials

**Diátaxis kind: tutorial.** A lesson. The reader is new and learns by doing something real, step by
step, with you guiding them. They should finish having done something that worked.

- Use one tutorial per learning goal. Name the file after the goal: `first-run.md`.
- Give every step. Don't offer choices or explain alternatives; that belongs in a how-to guide or an
  explanation.
- Show what the reader should see after each step, so they know it worked.

Guidance: [diataxis.fr/tutorials](https://diataxis.fr/tutorials/).
