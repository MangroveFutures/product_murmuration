# Reference

**Diátaxis kind: reference.** Facts to look up: commands, settings, environment variables, API
endpoints, data fields, error codes. The reader consults it while working; they don't read it start
to finish.

- Describe, don't instruct or explain. Keep each entry in the same shape.
- **Generate it from the code where you can** (an API reference from OpenAPI, a schema diagram from
  the models) and say in the file which command regenerates it. Hand-written reference drifts.
- Name files after what they describe: `environment-variables.md`, `api.md`.

Guidance: [diataxis.fr/reference](https://diataxis.fr/reference/).
